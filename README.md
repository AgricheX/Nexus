# Agriche Nexus

Central hub for Agriche's free WorldBox and RimWorld mods: direct downloads, detailed mod pages, guides and a help forum.

**Site: https://agrichex.github.io/Nexus/**

English first, português do Brasil logo abaixo.

---

## English

### What you will find

- **Every mod in one place**, organized by game: WorldBox (New Gen and Legacy) and RimWorld.
- **A page for each mod** with its features, animated sprites, items, settings and install steps.
- **Direct downloads** that always point to the latest release on GitHub.
- **Guides** for installing WorldBox and RimWorld mods.
- **A help forum** with topics for each mod.
- **Neo Mod Maker**, the free tool for creating WorldBox mods in your browser.
- English and Brazilian Portuguese.

### Mods

| Game | Mods |
| --- | --- |
| WorldBox (New Gen) | Godzilla, Civilizations, Ocean of Souls, ChatRealms |
| WorldBox (Legacy) | One Piece, Flag Box, Isekai, Invasions, Naval Battle, Magic Races, Nomes Brasileiros, Monster Mod |
| RimWorld | Endless Rooms, Sos2 Space Expanded |

### Help

Questions and bug reports: [Agriche Community on Discord](https://discord.gg/s3EbgNSsJW).

All mods are free, made by fans for fans. If anyone asks you for money to use them, it is a scam.

## Português (Brasil)

A central dos mods gratuitos da Agriche para WorldBox e RimWorld: downloads diretos, páginas detalhadas dos mods, guias e um fórum de ajuda.

### O que você encontra

- **Todos os mods num lugar só**, organizados por jogo: WorldBox (New Gen e Legacy) e RimWorld.
- **Uma página para cada mod** com recursos, sprites animados, itens, configurações e passo a passo de instalação.
- **Downloads diretos** que sempre apontam para a versão mais recente no GitHub.
- **Guias** de instalação de mods de WorldBox e RimWorld.
- **Um fórum de ajuda** com tópicos de cada mod.
- **Neo Mod Maker**, a ferramenta gratuita para criar mods de WorldBox no navegador.
- Inglês e português do Brasil.

### Ajuda

Dúvidas e bugs: [Agriche Community no Discord](https://discord.gg/s3EbgNSsJW).

Todos os mods são gratuitos, feitos de fã para fã. Se alguém pedir dinheiro para usar, é golpe.
